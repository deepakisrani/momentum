# Momentum

Momentum is a workout-planning and training-log PWA built with React, TypeScript, Vite, and
Supabase.

## Development

For the hosted Supabase project, copy `.env.example` to `.env.local` and add the project URL and
publishable key.

For a full local environment—including Postgres, Auth, Row Level Security, and migrations—follow
[Local development](docs/LOCAL_DEVELOPMENT.md).

## Checks

- `npm test`
- `npm run lint`
- `npm run build`
